# Support

Use the [GitHub issue tracker](https://github.com/NatLabRockies/pyTOST/issues)
for usage questions, installation problems, bug reports, and documentation requests.
Search existing issues first. For contribution instructions, see
[CONTRIBUTING.md](CONTRIBUTING.md).

For a reproducible report, include:

- The pyTOST version or commit, Python version, and operating system.
- A minimal example using synthetic or shareable data.
- The expected and observed behavior, including the full error message if applicable.
- The inference engine, options, and seed needed to reproduce the result.

Do not post confidential data or credentials. For a suspected security vulnerability,
contact dylan.hettinger@nlr.gov privately rather than publishing exploit details.
Report conduct concerns through [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Support is provided on a best-effort basis, with no guaranteed response time.
Maintainers prioritize reproducible correctness problems, installation failures, and
documentation that prevents use. A support request does not guarantee a fix or a
particular release date.

Statistical questions should describe the sampling design and intended estimand.
The package does not choose a scientifically appropriate equivalence margin for the
analyst, and support does not replace subject-matter or statistical review.
